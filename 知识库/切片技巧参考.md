# 切片技巧参考

## 核心原则

**从观众角度出发**：观众打开视频第一眼看到什么？听到什么？感受是什么？会不会划走？会不会看完？会不会点赞收藏？会不会关注？

## 开头3秒钩子（决定完播率的关键）

### 5种钩子类型
1. **痛点直击**：直接点出观众关心的问题
2. **悬念制造**："你绝对想不到接下来发生了什么"
3. **反常识**：打破常规认知
4. **时间压迫**："最后10秒，太刺激了"
5. **画面先行**：最精彩的画面放在最前面

### 3秒滑出率
- 超过45%直接限流
- 前3秒必须是最高潮/最吸引人的画面
- 不要用冗长的前奏/开场白

## 剪辑节奏

- **一句话剪成一段**，3-5秒切换镜头
- **直播素材调倍速1.1-1.2倍**，节奏更紧凑
- **不要七八秒、十几秒长片段直接照搬**
- **原素材单段不超过7-10秒**，素材要足够碎
- **画面切换频繁**，2-3秒切一个画面

## 字幕样式（高级感）

- **白色字体+阴影**，不加描边
- ❌ 不要大黄字+黑描边
- **推荐字体**：思源粗宋、金陵体、阳华体、俊雅体、景天体
- **关键词高亮**：重要歌词/金句用不同颜色标注
- **位置**：底部居中，避开安全区

## 封面设计

### 封面三要素
1. **大标题**：不超过12字
2. **高对比**：颜色撞色，小屏幕可读
3. **情绪脸**：人物特写，表情夸张

### 封面安全区
- 顶部220px、底部380px为UI安全区
- 标题和人物必须避开，否则被抖音点赞、文案、头像遮挡

### 封面禁忌
- ❌ 通用大字
- ❌ 没有人物特写
- ❌ 标题超过12字
- ❌ 文字被平台UI遮挡
- ❌ 低俗、擦边图片

## 去重体系（四层架构）

### 第一层：结构层（最有效）
- 打乱时序节奏，改变视频原有结构
- 非唱歌内容可调整片段顺序
- 用自己的观点重新安排镜头顺序

### 第二层：画面层
- 轻微放大+滤镜+锐化降噪
- 装饰元素：角标/进度条/弹幕/画中画
- 画面分割功能，拆解为多个片段重新排列

### 第三层：音频层
- 分离人声+更换BGM
- 加音效、音量调整
- ⚠️ 已禁用音频变速（音画不同步）

### 第四层：原创增量层
- 配音、字幕、节奏、开头到结尾全部换成自己的表达
- 视频结尾增加提问式互动
- 现场录音、数据图表、字幕设计

### 已失效的去重方法（不要用）
- 水平翻转
- 简单调色
- 加速1.1倍
- 静态贴纸
- 只改MD5

### 已验证去重ffmpeg参数
```
crop=iw*0.95:ih*0.95,scale=1080:1920,unsharp=5:5:0.8:5:5:0.0,eq=brightness=0.02:contrast=1.08:saturation=1.1
```
- libx264 crf 23
- aac 128k
- 永久禁用镜像翻转和音频变速

## 视频包装

### 转场效果
- 淡入淡出、闪白、缩放、滑动、故障风

### 调色风格
- 暖色调、高对比、电影感

### 装饰元素
- 角标（战队名/选手名）、进度条、弹幕、画中画

### BGM和音效
- 热门BGM（注意版权）、转场音效、高光音效、搞笑音效

## 发布策略

### 发布时间
- 第一条立即发布
- 其他定时发布，间隔≥2小时
- 所有切片必须在第二天内全部发布完成
- 不能留到第三天（超过第二天没人看）

### 每天发布数量
- 常规：每天最多3-4条，类型交替
- 不要一口气发太多（平台会限流）

### 发布前检查清单
- [ ] 时长合适？（唱歌/比赛必须完整）
- [ ] 前3秒是最高潮？
- [ ] 结尾有关注引导文字？
- [ ] 标题是冲突/悬念式？
- [ ] 音频检查通过（有声音）？
- [ ] 封面设置完成？
- [ ] 自主声明"虚构演绎，仅供娱乐"？
- [ ] 发文助手检测通过？

## 音频检查（9/23无声事故教训）

**每条切片后必须用ffprobe/volumedetect检查音频流，确认有声音再发布！**

```bash
ffmpeg -i input.mp4 -af volumedetect -f null -
```
检查 mean_volume 是否在正常范围（-12~-16dB）

## 卖货视频处理

- 卖货视频不切片不发布（三重检测）
- 如恢复卖货切片：每个商品只切一个完整片段，不拆分
- 卖货视频保存到桌面，用户用手机发布并挂商品链接
