# 抖音规则速查

## 推荐算法权重（2026年最新）

| 排名 | 指标 | 权重 | 说明 |
|------|------|------|------|
| 1 | 收藏率 | ~40% | 第一核心指标 |
| 2 | 复访率 | ~20% | 用户主动回访 |
| 3 | 铁粉互动 | ~20% | 铁粉权重是普通用户7倍 |
| 4 | 5秒完播率 | ~15% | 冷启动关键 |
| 5 | 整体完播率 | - | 基础门槛 |
| 6 | 评论质量 | - | 优质评论 |
| 7 | 点赞 | - | 权重较低 |
| 8 | 转发 | - | 权重最低 |

### 7天长效推流机制
- 第1-2天：冷启动（200-500播放测试）
- 第3-4天：二次激活
- 第5-7天：收藏复看长尾爆发

### 搜索流量
- 搜索流量占比超50%
- 前5秒亲口说关键词可匹配搜索流量

## 直播切片四条红线（绝对不能碰）

1. **必须有授权**：拿到主播授权再做切片
2. **必须二次创作**：不能原封不动搬运，必须做二次创作
3. **必须标注来源**：清晰标注素材来源
4. **不能恶意引导**：不能用夸张、误导、强迫等方式引导互动

## AI内容标注要求

- AI生成内容必须标注
- 自主声明选「虚构演绎，仅供娱乐」
- 违规限流50%-80%
- 每次发布都必须设置自主声明

## 内容审核规则

### 标题与封面
- 避免夸大、误导和虚假承诺
- 标题真实反映内容
- 封面不使用低俗、擦边图片
- 不使用极限词（最、第一、绝对等）

### 口播与文案
- 表达真实清楚
- 不使用极端话术
- 不使用谐音变体规避检测
- 不涉及敏感话题

## 处罚规则

- **处罚叠加**：多项违规按最严重处罚，单场多次违规叠加
- **谐音变体识别升级**：避免谐音梗
- **AI内容违规**：限流50%-80%

## 去重检测机制（五重检测）

1. **MD5**：文件指纹
2. **画面抽帧**：视频内容比对
3. **音频指纹**：声音内容比对
4. **OCR文字**：字幕文字比对
5. **暗水印**：隐藏水印追踪

### 单素材连续使用限制
- 连续使用同一种素材超过15秒没有二次加工，被系统直接判定为低质量搬运内容

## 发布规范

### 发布时间
- 第一条立即发布
- 其他定时发布，间隔≥2小时
- 所有切片必须在第二天内全部发布完成
- 不能留到第三天

### 发布数量
- 常规每天最多3-4条，类型交替
- 不要一口气发太多（平台会限流）

### 发布前必须
- 上传等100%+系统检测完成
- 发文助手检测无违规
- 自主声明选「虚构演绎，仅供娱乐」
- 每个视频都必须设置封面
- 发布成功后去内容管理页面确认

## 封面规范

- 顶部220px、底部380px为UI安全区
- 标题不超过12字
- 人物占画面60%以上
- 白色文字+黑色阴影，不加粗黑描边

## 合规风险提醒

- **跳舞动作可能违规**
- **卖货视频**：按规则不切片不发布
- **明星相关视频**：不切片不发布
- **版权音乐**：注意音乐版权
