# 木森大舞台直播切片自动化工具

木森大舞台直播录像智能切片、去重、发布全流程自动化工具。

## 功能
- 直播录屏分析与高光识别
- 四层去重体系（结构层/画面层/音频层/原创增量）
- 视频质量检测与打分
- 自动生成标准化封面
- 抖音发布全流程自动化
- 竞品账号监控与去重策略

## 适用场景
- 直播切片运营
- 短视频批量制作
- MCN机构内容生产

## 使用方法
1. 配置录屏目录路径
2. 运行 smart_clip.py 开始切片
3. 按提示完成发布流程

## 注意事项
- 需自行配置ffmpeg路径
- 需自行配置抖音创作者中心登录态
- 卖货视频和明星相关视频不切片不发布
- 唱歌和比赛环节必须完整切片
